# Python Internship Projects

## 📌 Project Title

**Python Internship – Task Projects**

This repository contains the Python projects and tasks completed as part of my internship. These projects helped me improve my understanding of Python programming, problem-solving, and basic application development.

## 🛠️ Technologies Used

- **Python 3**
- Python Standard Library
- **VS Code** – for development
- **Git & GitHub** – for version control and project management

## 📂 Projects

### Task 1 – Calculator
A simple command-line calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

### Task 2 – To-Do List
A command-line to-do list application that allows users to add, view, and remove tasks. Tasks can be stored during runtime and optionally saved to a text file.

### Task 3 – Number Guessing Game
A number guessing game where the computer generates a random number and the user tries to guess it. The program provides **"Too High"** or **"Too Low"** hints and tracks the number of attempts.
